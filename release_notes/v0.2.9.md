# v0.2.9 - 2026-04-13

## Changes

### Intelligent View Virtualization
Context-aware view virtualization detects when internal tools, settings, or the landing page are in use and detaches the BrowserView engine. Reduces CPU and battery usage during background sessions.

### Professional PDF Orchestration
- All PDFs now include an auto-generated clickable Table of Contents
- Electron's native header and footer templates for page numbering, preventing number cropping or misalignment

### Standardized Desktop HIG
- AI Sidebar and URL Bar now share a unified 56px header height
- Provides more vertical space while aligning icons/text with macOS traffic lights and window controls

### Streamlined Onboarding
- "Get Started" path guides through StartupSetupUI with intelligent transitions
- Successful AI provider verification (Ollama/OpenAI) automatically advances to the next phase

### Build Highlights
- **Stability**: Fixed React lifecycle errors in the sidebar
- **Visuals**: Corrected icon transparency in packaged production builds
- **Performance**: Event-gating for window resize listeners
