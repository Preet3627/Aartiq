# v0.3.4

Released: July 19, 2026

## Highlights

### AI Chat & Sidebar
- **Smart message rendering** with expandable results, code blocks, and structured output display
- **SEARCH_RESULTS** now auto-navigates and reads full page content
- **Removed automatic pre-flight web search** — AI decides when to search
- **Replaced failing web search** with MCP backend, skill-based prompt injection, and DOM_SEARCH fallbacks
- **Simplified tool output bubbles** to minimal expandable text
- **Keyboard shortcuts** for AI controls (open/close sidebar, new conversation, toggle)

### Command Palette & UI
- **Searchable ⌘K command palette** for all actions and settings
- **Vertical timeline** with timestamps for action chain
- **Agent state indicator** with all states (idle, thinking, executing, waiting, error)
- **Action cards** show reason, risk level, and required permission
- **Clean progress results** instead of raw terminal output

### Security & Permissions
- **Medium-risk approval required** for sensitive operations
- **High-risk actions always require Touch ID** (macOS) / Windows Hello (Windows)
- **Per-action 5-question trust model** for transparent AI decisions
- **Batch permissions** and auto-approve for trusted low-risk actions

### Automation & DOM Engine
- **Centralized DOM interaction engine** with centralized command registry
- **Multi-strategy fallback chain** for DOM click element
- **MULTI_FILL_FORM** command with atomic multi-field filling
- **CLICK_AT, SCROLL_TO, FILL_FORM** commands added to registry
- **Workflow recording/playback** with DOM-aware steps
- **AutomationManager** persistence and CRUD operations

### PDF & Document Generation
- **Crash-proof PDF templates** in main.js
- **Simplified PDF generation** with source favicons
- **Fixed React hydration errors** in PDF generation

### TypeScript & Build
- **All TypeScript build errors resolved** in aartiq-browser
- **Type fixes**: multiFillForm signature, Ollama callbacks, Ollama model imports, Azure OpenAI properties
- **Swift build fix**: ApprovalCard body split to resolve type-checker timeout

### MCP Server (v2.0.0)
- **Rewritten with 64 tools** and HTTP bridge (port 46203)
- **New bridge endpoints**: sidebar, bookmarks, history, settings, permissions, automation tasks
- **Claude Desktop .mcpb extension** built in release workflows
- **Token-based pairing** with security model (biometric for high-risk, per-action approval for medium-risk)
- **Removed extra entitlements** and duplicate MCP approval popup HTML

### DevOps & Infrastructure
- **Domain migration**: aartiq.com → aartiq.ponsrischool.in
- **CI builds .mcpb** extension automatically in release workflows
- **Auto-link .mcpb** in README on release

### Documentation
- **Rewritten README** with badges, comparison table, architecture diagram
- **Claude MCP Architecture guide** added
- **Removed screenshots section** for cleaner docs
- **Dual-license docs** added to CONTRIBUTING and aartiq-browser README
