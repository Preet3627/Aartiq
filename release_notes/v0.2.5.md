# v0.2.5 - 2026-03-26

## Changes

### Automation Panel
- Automation section available in Settings panel
- View, filter (All/Active/Paused), and manage scheduled tasks
- "+ Create Task" button opens scheduling modal
- Fixed panel overflow with scrollable task list

### AI Commands
- `OPEN_AUTOMATION_SETTINGS` - AI can open automation settings directly
- `OPEN_SCHEDULING_MODAL` - AI can prefill and open scheduling modal with data
- `SCHEDULE_TASK` now uses JSON format exclusively

### Panel Updates
- Translate Panel: added scrolling with max-height limit
- All panels now appear above browser view (z-index 9999)
- Browser view disabled when panels open

### Bug Fixes
1. Fixed duplicate import of SpotlightSearchOverlay
2. Fixed crash when automation service not initialized
3. Fixed syntax errors from incorrect code blocks in ClientOnlyPage parsing
4. Fixed useEffect missing dependency array causing infinite loop

### Other
- Removed deprecated GENERATE_PDF format from AI guide
- PDF template markers now properly passed to generator
- All version references updated to v0.2.5
