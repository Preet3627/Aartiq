# v0.2.9.3 - 2026-04-20

**Channel:** Stable

## Changes

Introduces platform ecosystem integration across macOS, Windows, and Linux with native alternatives for automation and OCR. Includes post-release stability repairs for macOS packaged builds.

### What's New

| Feature | Platform | Description |
|---------|----------|-------------|
| **Siri / Shortcuts** | macOS | `comet-ai://` deep-link actions for Shortcuts and Siri-triggerable custom shortcuts |
| **Windows Shortcuts** | Windows | Shortcuts + Voice + Copilot |
| **Linux Desktop** | Linux | GNOME/KDE/XFCE/MATE |
| **Native Click** | All | steve, nut.js, xa11y |
| **Native OCR** | All | uniOCR, RustO! (99.3%) |

### macOS Integration

#### Siri & Apple Shortcuts
URL Scheme `comet-ai://` with 12 pre-configured actions:

| URL | Action |
|-----|--------|
| `comet-ai://chat?message=...` | Send message to AI |
| `comet-ai://search?query=...` | Web search |
| `comet-ai://create-pdf?content=...&title=...` | Generate PDF |
| `comet-ai://navigate?url=...` | Open URL |
| `comet-ai://run-command?command=...` | Run command |
| `comet-ai://volume?level=0-100` | Set volume |
| `comet-ai://open-app?appName=...` | Open app |
| `comet-ai://screenshot` | Capture screen |
| `comet-ai://schedule?task=...&cron=...` | Schedule task |
| `comet-ai://ask-ai?prompt=...&speak=true` | Ask + Speak |

Siri voice commands via Shortcuts.

#### Voice Control
- Dictation: Press Cmd+Shift+D to dictate
- Text-to-Speech: AI responses spoken aloud
- AppleScript Bridge: Pre-built automation scripts

### Native Click Alternatives
Cross-platform automation priority chain:

| Priority | macOS | Windows | Linux |
|----------|-------|---------|-------|
| 1st | steve CLI (AXUIElement) | nut.js | xdotool |
| 2nd | AppleScript | xa11y | xte/xinput |
| 3rd | robotjs | robotjs | robotjs |

### Native OCR Alternatives

| Priority | macOS | Windows | Linux |
|----------|-------|---------|-------|
| 1st | uniOCR (Vision) | uniOCR (Windows) | uniOCR (Tesseract) |
| 2nd | RustO! (PaddleOCR) | RustO! | RustO! |
| 3rd | Native Vision API | Windows OCR | AT-SPI2 |
| 4th | Tesseract.js | Tesseract.js | Tesseract.js |

Performance: uniOCR (3.2 img/s, 90% accuracy), RustO! (99.3% accuracy), Tesseract.js (99%+ on printed text).

### Bug Fixes
1. **PDF Generation** - Removed "Protected Ecosystem" watermark footer
2. **macOS Build** - Fixed with ad-hoc signing: `--c mac.signingIdentity='-'`
3. **macOS Packaged Performance** - Default packaging switched to native `arm64` (removed Rosetta-only default path for M-series)
4. **Siri / Shortcuts** - Fixed broken `comet-ai://` packaged protocol registration; fixed URL parsing bug that treated shortcut actions as `index`; fixed startup deep-link handling for shortcut launches
5. **GitHub Actions** - Fixed code signing error (empty password)
