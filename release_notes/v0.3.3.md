# v0.3.3

## Changes

### Claude Desktop MCP Server — 64 Tools

Complete rewrite of the MCP server from 21 standalone tools to **64 integrated tools** that give Claude Desktop full control over a running Aartiq browser.

#### Architecture

- **stdio ↔ HTTP bridge**: MCP server runs as a Node.js process (stdio transport) and communicates with the Aartiq browser over HTTP (port 46203)
- **No standalone fallback**: All tools require the Aartiq browser to be running — this means Claude gets the full AI pipeline (RAG, web search, PDF generation, navigation, structured output) instead of dumb standalone commands
- **AI sidebar integration**: `send_ai_prompt` goes through the actual AI sidebar component, not the simplified `/cli/ask` endpoint

#### Key Improvements

- **Full AI capabilities**: Claude can generate PDFs, search the web, navigate pages, extract content, and run structured commands — all through the real AI sidebar
- **Bookmarks management**: Claude can add, list, and remove bookmarks
- **History access**: Claude can browse and clear browsing history
- **Settings control**: Claude can read and modify any browser setting
- **Scheduled tasks**: Claude can create, list, toggle, delete, and run scheduled tasks
- **Permission management**: Claude can list, grant, and revoke permissions
- **Security management**: Claude can read security settings, update them, and change firewall levels
- **Panel control**: Claude can open any browser panel (settings, history, bookmarks, downloads, clipboard, permissions, sync, command center)
- **App knowledge**: Claude has built-in knowledge of all Aartiq features and security architecture

#### Bridge Endpoints Added

New HTTP endpoints in `main.js` (port 46203):
- `GET /sidebar-state`, `POST /sidebar/open`, `POST /sidebar/close`, `POST /sidebar/toggle`
- `GET /bookmarks`, `POST /bookmarks/add`, `POST /bookmarks/remove`
- `GET /history`, `POST /history/clear`
- `GET /settings`, `POST /settings/update`
- `GET /permissions`, `POST /permissions/grant`, `POST /permissions/revoke`
- `GET /automation/tasks`, `POST /automation/tasks/create`, `POST /automation/tasks/toggle`, `POST /automation/tasks/delete`, `POST /automation/tasks/run`
- `GET /app-info`
