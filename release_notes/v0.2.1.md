# v0.2.1 - 2026-02

## Changes

- **Command orchestration rewrite**: Unified agent action execution with result harvesting before final synthesis. The AI observes results of web searches and shell commands before generating responses.
- **Command scoping**: Distinguishes executable commands (`[NAVIGATE]`, `[SHELL_COMMAND]`, `[GENERATE_PDF]`) from meta commands (`[EXPLAIN_CAPABILITIES]`, `[LIST_OPEN_TABS]`). Commands inside markdown tables or code blocks are ignored.
- **Visual Intelligence Registry**: Sparkles icon in header opens a glassmorphic panel listing available tools with descriptions and examples. Accessible via `[EXPLAIN_CAPABILITIES]` in chat.
- **Advanced Web Search (RAG)**: `[WEB_SEARCH]` navigates the browser to display results while extracting data into context.
- **Professional PDF Generator**: Restored `[GENERATE_PDF]` with fixed parameter engine.
- **Shell Access**: Restored `[SHELL_COMMAND]` with high-risk user permission layer.
- **Local Model Support**: Native support for GPT-OSS-Cloud 120B models via Ollama. Hardware warnings for models exceeding available RAM.
- **UI Polish**: Redesigned glassmorphic send button, collapsible thinking panel, fixed three-dot header/footer menus.

## Bug Fixes
- AI repeating "DEFAULT_RULES" or system instructions in a loop
- Command parser picking up example tags in documentation
- Ollama models with "gpt" in the name incorrectly routed to OpenAI
- Argument count mismatch in PDF generation utility

- **Clipboard Sync**: Overhauled mobile-to-desktop clipboard syncing over primary WebSocket (instead of WebRTC)
