# v0.2.3 - 2026-03-15

## Changes

### Secure DOM Reading
- **PII Redaction**: Automatically removes emails, phones, tokens, and credentials from page content
- **Injection Detection**: Blocks prompt injection patterns using existing threat detection system
- **Filtered Element Tree**: Scripts, styles, navigation, ads, and tracking elements are automatically blocked
- **DOM Search**: New `[DOM_SEARCH: query]` command to search within the current page
- **DOM Read Filtered**: New `[DOM_READ_FILTERED: query]` command with comprehensive filtering

### Screenshot Embedding in PDFs
- AI can take screenshots during demonstrations and embed them in PDF reports
- PNG/JPEG image embedding with optional captions and responsive sizing

### Enhanced EXPLAIN_CAPABILITIES
Executes real tasks live:
1. Web Search - fetches latest technology news
2. Shell Commands - retrieves WiFi/network information per OS
3. System Control - adjusts volume to 50%
4. App Launching - opens Calculator (auto-detected per platform)
5. Screenshot Capture - takes and embeds screen images
6. PDF Generation - creates branded reports with embedded screenshots

### New Commands
| Command | Description |
|---------|-------------|
| `[DOM_SEARCH: query]` | Search within current page DOM |
| `[DOM_READ_FILTERED: query]` | Read DOM with security filtering and optional search |
| `[SCREENSHOT_AND_ANALYZE]` | Capture screen and extract text via OCR |

### Enhanced PDF Generation
- `buildCleanPDFContent()` now accepts optional `images` parameter
- New `buildCapabilityReportPDF()` function for reports
- Image captions and responsive sizing

### Security Improvements
- Extended PII patterns (phone numbers, credit cards, session tokens)
- Enhanced injection pattern detection
- Read-only DOM enforcement in system instructions
- Filter statistics displayed in sidebar

### UI Improvements
- DOM Search Display with real-time results, XPath, and relevance scoring
- Security badges for safe/warning/danger states
- Expandable results with full context and metadata
- Timestamp display on search results
- Gradient backgrounds, improved badge styling, better spacing and typography, enhanced hover states

## Bug Fixes
- Fixed `DOMSearchResult` and `DOMElement` interface compatibility
- Added optional chaining for optional properties
- Resolved undefined property issues in image embedding

## Technical Details

### SecureDOMReader
```typescript
class SecureDOMReader {
  detectInjection(content: string): { detected: boolean; patterns: string[] }
  extractContent(html: string, url: string): FilteredDOMResult
  searchDOM(elements: DOMElement[], options: DOMSearchOptions): DOMSearchResult[]
  buildContextForAI(result: FilteredDOMResult, searchQuery?: string): string
}
```
