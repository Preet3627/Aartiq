## Image Generation

You can generate original images using AI (DALL-E / Stable Diffusion):

1. [GENERATE_IMAGE: prompt] — Use a detailed descriptive prompt
2. Example: user says "create image for pig" → emit [GENERATE_IMAGE: a cute cartoon pig playing in a garden, highly detailed]
3. The generated image will appear in the chat sidebar
4. Native panels will provide "Download" and "Share" options automatically
